# synthroute

**Verifier-gated AI synthesis planning.** От названия препарата (МНН) к нескольким проверенным вариантам маршрута синтеза:
схема, источники, статусы проверки, метрики, правка в диалоге и экспорт в автономный HTML и PDF.

> **Статус:** ранняя стадия. Готовы каркас правил и документации, код появится в следующих этапах.
> Направление проекта описано в [`docs/vision/north-star.md`](docs/vision/north-star.md).

## Почему не просто LLM
LLM предлагает маршруты, но выдумывает реакции, реагенты и ссылки. В synthroute каждый шаг проходит детерминированные проверки,
а каждый факт помечен источником и статусом: **подтверждено литературой**, **подтверждено расчётом** или **гипотеза модели**.

## Компоненты (план)
| Компонент | Что это |
|---|---|
| RouteSpec | открытый JSON-формат маршрута ([ADR-0003](docs/adr/0003-routespec-open-format.md)) |
| route-lint | детерминированные проверки с кодами диагностик |
| route-viewer | интерактивная схема маршрута на Vue Flow |
| SynthBench | бенчмарк для сравнения с LLM без обвязки |

## Ответственное использование
Учебно-исследовательский инструмент только для одобренных препаратов. Маршруты не являются подтверждённой технологией.
Подробности в [`RESPONSIBLE_USE.md`](RESPONSIBLE_USE.md).
