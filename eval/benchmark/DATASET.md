# Карточка набора: пул кандидатов бенчмарка v0

- **Файл:** `eval/benchmark/candidates_v0.csv` (одна строка на препарат-кандидат)
- **Статус:** пул кандидатов для будущего бенчмарка. Это ещё **не** бенчмарк и не сплит: маршруты не собраны,
  квоты по классам уровня маршрута задать пока не из чего, каталог `eval/benchmark/test/` не создавался
  (EVAL-002). Квоты структурных классов (F8) применены, доли проверены — см. `eval/reports/coverage.md`.
- **Дата выгрузки источников:** 2026-10-13 (дата среза для патентного статуса — тоже 2026-10-13).
- **Как воспроизвести (EVAL-001):** из корня репозитория

  ```bash
  uv run --no-project --python 3.12 --with rdkit --with requests --with pandas --with numpy eval/select_benchmark.py
  ```

  Скрипт кэширует ответы ChEMBL, Orange Book и Europe PMC в `data/cache/` (не в git, DATA-002); `--refresh`
  скачивает их заново. Версии библиотек, хэш скрипта, `git_sha` и версии источников записываются в
  `eval/reports/coverage.json`.
- **Сопутствующие файлы:** `eval/reports/coverage.md` и `coverage.json` (воронка и проверка покрытия),
  `eval/reports/exclusions.csv` (причина исключения по каждой молекуле на шагах F2–F5).

## Назначение

Отобрать одобренные малые молекулы, из которых будет собран бенчмарк «МНН → проверенные варианты маршрута», и
измерить, насколько выборка из 40 позиций воспроизводит реальную популяцию одобренных малых молекул по классам
задачи (N-гетероциклы, фтор, хиральность) и по свойствам (MW, cLogP, TPSA, Fsp3). Выборка собирается по
разнообразию структур с квотами классов (F8), чтобы разнообразие не вытесняло из неё реальные пропорции.
Методика описана в `docs/research/03-data-and-rag.md`, разделы 2 и 3.

## Состав

Только идентификаторы и вычисленные свойства. Маршрутов, реагентов, условий и любой другой информации о синтезе
в наборе нет и не будет на этом этапе (SAFE-*, `RESPONSIBLE_USE.md`).

| Столбец | Тип | Описание |
|---|---|---|
| `chembl_id` | str | ChEMBL ID родительской записи |
| `inn` | str | МНН (синоним ChEMBL с `syn_type = INN`, нижний регистр) |
| `first_approval` | int | год первого одобрения по ChEMBL (`first_approval`) |
| `patent_status` | str | `off_patent_us` для всех строк пула (справка по Orange Book на дату среза, SAFE-005) |
| `epmc_hits` | int | число записей Europe PMC по запросу-прокси F5 |
| `n_heterocycle` | bool | есть кольцо (ароматическое или алифатическое), содержащее N |
| `has_F` | bool | есть атом фтора |
| `n_stereo` | int | число стереоцентров, включая неназначенные (`FindMolChiralCenters`, `includeUnassigned=True`) |
| `mw`, `clogp`, `tpsa`, `fsp3` | float | MolWt, Crippen cLogP, TPSA, доля sp3-углерода (RDKit) |
| `scaffold_id` | str | `gs_` + первые 10 символов SHA-1 от SMILES обобщённого каркаса Bemis–Murcko; `acyclic` для молекул без колец |
| `selected_in_40` | bool | молекула попала в выборку из 40 (F8: квоты классов + MaxMin) |
| `ru_list_check` | str | `pending_manual` для всех: сверка с ПП РФ № 681 вручную ещё не сделана |
| `hbd`, `hba` | int | доноры и акцепторы водородной связи (RDKit `CalcNumHBD`/`CalcNumHBA`) |
| `n_ring_systems` | int | число кольцевых систем (кольца с общими атомами объединены) |
| `n_heavy_atoms` | int | число тяжёлых атомов |
| `inchikey` | str | InChIKey родительской структуры после `rdMolStandardize.FragmentParent` |

Все свойства считаются по родительской структуре после `rdMolStandardize.FragmentParent` (RDKit).

## Способ получения (воронка)

Подробные числа по каждому шагу — в `eval/reports/coverage.md`.

| Шаг | Что делает |
|---|---|
| F1 | ChEMBL `max_phase = 4`, `molecule_type = Small molecule`; только записи, где `parent_chembl_id == molecule_chembl_id` |
| F2 | есть синоним с `syn_type = INN` |
| F3 | есть структура в ChEMBL и нет флагов `polymer_flag`/`inorganic_flag`; RDKit: структура разбирается без ошибок санитизации, нет изотопной метки, нет металлов и металлоидов (кроме B, Si, Se), есть углерод, одна компонента после удаления стандартных солей и растворителей, MW ≤ 900, меньше 8 α-аминоацильных амидных связей, есть InChIKey. Выжившие образуют **референсную популяцию** |
| F4 | Orange Book: названия сопоставляются без учёта регистра, слова-соли удаляются; если есть монопрепараты вещества, статус считается по ним, иначе по всем продуктам. Любая строка Patent.txt или Exclusivity.txt с датой позже 2026-10-13 даёт `protected`, отсутствие таких строк — `off_patent_us`, отсутствие вещества в Orange Book — `unknown`. В пул идут только `off_patent_us` |
| F6 | гейт fail-closed: исключаются вещества, чьё МНН, основное название или синоним-название (после удаления солей и, для гейта, эфирных суффиксов) совпадает с действующим веществом продуктов NDC, у которых есть DEA schedule, или встречается в тексте 21 CFR 1308.11–1308.15. Если любой из этих источников недоступен, скрипт завершается до записи результатов. Источники гейта не кэшируются, названия исключённых веществ нигде не выводятся |
| F5 | прокси документированности: Europe PMC, `TITLE_ABS:"<МНН>" AND (TITLE_ABS:"synthesis" OR TITLE_ABS:"process development")`, нужно ≥ 2 записей; не больше 4 запросов в секунду, ответы кэшируются |
| F7 | на каждый обобщённый каркас Bemis–Murcko остаётся одна молекула: с наибольшим `epmc_hits`, при равенстве — с меньшим ChEMBL ID |
| F8 | выборка 40 позиций: жадный MaxMin по Morgan r=2, 2048 бит с квотами структурных классов. Окно квоты класса — его доля в референсной популяции ±5 п.п. (половина допуска покрытия), пересчитанная в позиции. Фаза А добирает нижние границы, начиная с самого редкого класса, фаза Б тратит остальные позиции на разнообразие, верхние границы действуют всегда. Случайного старта нет: при равенстве расстояний берётся более документированная молекула, затем с меньшим ChEMBL ID. Для сравнения считается та же выборка без квот (`MaxMinPicker.LazyBitVectorPick`, seed 42) — её состав и разнообразие записаны в `coverage.json` |

## Безопасность

- В наборе нет никакой информации о синтезе: только идентификаторы и вычисленные свойства.
- Гейт F6 работает по принципу fail-closed (SAFE-002) и при совпадении исключает с запасом: openFDA возвращает
  все действующие вещества продуктов с DEA schedule, в том числе сопутствующие вещества комбинаций.
- Сверка с перечнем ПП РФ № 681 не автоматизирована (машиночитаемого официального формата нет), поэтому у всех
  строк стоит `ru_list_check = pending_manual`. До заморозки бенчмарка её нужно выполнить вручную и
  зафиксировать результат вместе с источником и датой редакции перечня (SAFE-003).
- Перечни INCB и OPCW пока не проверялись.

## Известные ограничения и смещения

1. **F5 — прокси.** Число записей Europe PMC не равно «двум независимым источникам с восстановимыми
   промежуточными веществами» из методики. Слово «synthesis» часто относится к биосинтезу или синтезу ДНК и
   белка, а общеупотребимые или короткие МНН дают ложные совпадения.
2. **Патентный статус только по США.** Используется одна ежемесячная выгрузка Orange Book и сопоставление по
   названиям. Вещества, которых нет в Orange Book (в том числе не продаваемые в США), получают `unknown` и в пул
   не попадают, что смещает пул к препаратам рынка США. Формуляционные патенты тоже дают `protected`. Это
   справка, а не юридическое заключение (SAFE-005).
3. **Гейт F6 работает по названиям, а не по структурам.** NDC покрывает только продукты, которые сейчас
   числятся в справочнике. Текст 21 CFR сопоставляется только по названиям, поэтому аналоги и вещества под
   другими названиями гейт не ловит.
4. **Одобрение и МНН подтверждены только по ChEMBL.** Подтверждение вторым регулятором и сверка с перечнями
   WHO INN ещё не сделаны.
5. **Смещение отбора.** MaxMin тянет выборку к структурно необычным молекулам, а правило «один препарат на
   каркас» — к редким каркасам. Квоты F8 возвращают в допуск доли трёх структурных классов (N-гетероцикл,
   фтор, стереоцентр), но это не стратифицированная выборка: внутри окна квоты решает только разнообразие, а
   балансировки по ATC-классам и году одобрения нет. Насколько отбор сдвигает доли и непрерывные свойства —
   показано в `eval/reports/coverage.md`, там же выборка без квот для сравнения.
6. **Классы уровня маршрута не измерены.** Защитные группы, каталитические стадии, биокатализ, длина и
   конвергентность маршрута появятся только после сбора маршрутов, поэтому квоты F8 заданы пока только по
   структурным классам.
7. **Дрейф источников.** Повтор с `--refresh` или в другой день может дать другие числа: ChEMBL выпускает новые
   релизы, Orange Book обновляется ежемесячно, а источники гейта запрашиваются заново при каждом запуске.
