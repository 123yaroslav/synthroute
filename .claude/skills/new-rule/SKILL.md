# Добавить правило

1. Прочитай `docs/rules/README.md` (анатомия) и индекс правил в `AGENTS.md`.
2. Выбери файл по области. Если подходящего нет, создай новый файл в `.claude/rules/<группа>/`
   с уникальным префиксом и `paths:` и добавь строку в индекс `AGENTS.md`.
3. Назначь следующий свободный номер `ПРЕФИКС-NNN`. Номера из `docs/rules/RETIRED.md` использовать нельзя.
4. Сформулируй правило одной императивной строкой и заполни **Почему** и **Проверка**.
   Сначала ищи способ автоматической проверки (хук, линтер, тест, схема). Если автоматизация пока не сделана, поставь `[todo]`.
5. Уровень `MUST` используй только для того, нарушение чего действительно должно блокировать мерж.
6. Запусти `make rules`, исправь ошибки и покажи пользователю дифф и строку итоговой сводки.
7. Если правило архитектурное, предложи создать ADR через `/new-adr`.
