# CORE — Базовые принципы работы

> Действуют всегда и для всех: людей и агентов.

### CORE-001 · MUST · Работай маленькими проверяемыми шагами
- **Почему:** большие непроверенные изменения скрывают ошибки; принцип «итерации, а не океан за раз».
- **Проверка:** review — PR с одной целью, каждый шаг подтверждён тестом или запуском.

### CORE-002 · MUST · Сначала диагностика, потом лечение
- **Почему:** исправление наугад порождает новые баги. Неочевидную причину нужно воспроизвести минимальным примером или найти по логам.
- **Проверка:** review — в описании фикса указана найденная причина.
- **Исключения:** опечатки и забытые импорты исправляются сразу.

### CORE-003 · MUST · Не изобретай велосипед: бери проверенные библиотеки
- **Почему:** химию, валидацию данных, PDF и аутентификацию с нуля не пишут (RDKit, Pydantic, Playwright и т. п.).
- **Проверка:** review

### CORE-004 · MUST · Секреты не попадают в git, логи, промпты и фикстуры
- **Почему:** утёкший ключ скомпрометирован навсегда. Ключи хранятся только в `.env`, который не коммитится.
- **Проверка:** auto:hook + auto:ci — хук блокирует запись в `.env`, gitleaks в pre-commit и CI

### CORE-005 · MUST · Не выдумывай: непроверенное помечай явно
- **Почему:** главный риск проекта — правдоподобные галлюцинации (DOI, условия, API библиотек).
- **Проверка:** agent — сначала проверить по документации или источнику, иначе написать «не проверено».

### CORE-006 · SHOULD · Простые задачи решай просто
- **Почему:** сложность — это цена, которую платят, только когда задача её требует.
- **Проверка:** review

### CORE-007 · MUST · Пользователю — понятное действие, в лог — подробности
- **Почему:** внутренности системы не помогают пользователю, а детали нужны для отладки.
- **Проверка:** review + auto:test — тесты API проверяют, что в ответах с ошибкой нет трейсбеков [todo]

### CORE-008 · MUST · Изменение поведения сопровождается тестами и документацией в том же PR
- **Почему:** документация, отставшая от кода, хуже отсутствующей.
- **Проверка:** review — чек-лист в шаблоне PR
