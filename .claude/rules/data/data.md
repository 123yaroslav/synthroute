# DATA — Данные и источники

> Данные являются частью вклада статьи. Их происхождение и лицензия должны быть безупречны.

### DATA-001 · MUST · У каждого набора данных есть карточка `DATASET.md`
- **Почему:** в карточке указаны источник, лицензия, дата выгрузки, способ получения, известные ограничения и смещения (формат datasheet).
- **Проверка:** auto:ci — скрипт ищет карточку в каждой папке `data/*/` [todo]

### DATA-002 · MUST · Сырые данные (`data/raw/`) не коммитятся и не правятся руками
- **Почему:** производные данные получаются только скриптами, иначе их невозможно воспроизвести.
- **Проверка:** auto:hook — хук блокирует запись агентом, `.gitignore`

### DATA-003 · MUST · Лицензии и условия использования источников соблюдаются
- **Почему:** без лицензионной чистоты датасет нельзя опубликовать вместе со статьёй. Где скрейпинг запрещён, он не используется.
- **Проверка:** review

### DATA-004 · MUST · Файлы больше 1 МБ не хранятся в git
- **Почему:** большие файлы раздувают репозиторий навсегда. Их место — релизы GitHub, Hugging Face Hub или DVC.
- **Проверка:** auto:hook — `check-added-large-files` в pre-commit

### DATA-005 · SHOULD · Фикстуры тестов маленькие и лежат в `data/fixtures/` с указанием происхождения
- **Почему:** тесты должны быть быстрыми и понятными.
- **Проверка:** review
