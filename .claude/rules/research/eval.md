# EVAL — Бенчмарк, эксперименты, статья

> Планка — рецензенты A*-конференции. Каждое число должно выдерживать вопрос «как это воспроизвести?».

### EVAL-001 · MUST · Каждое число в отчёте или статье воспроизводится командой из `eval/`
- **Почему:** результат прогона хранит `git_sha`, конфиг, версии моделей, промптов и проверок. Таблицы и графики статьи строятся только скриптом (`make paper-figures`).
- **Проверка:** auto:test — раннер отказывается писать результат без метаданных [todo]

### EVAL-002 · MUST · Тестовый сплит бенчмарка заморожен; агенты не читают эталонные ответы
- **Почему:** подгонка промптов под тест обесценивает статью. Любое изменение теста оформляется только через ADR.
- **Проверка:** auto:hook — запись и чтение `eval/benchmark/test/**` запрещены агенту в `.claude/settings.json`

### EVAL-003 · MUST · Рядом всегда базовая линия «LLM без обвязки» с тем же бюджетом
- **Почему:** главная гипотеза проекта — превосходство над одной LLM по точности и стоимости.
- **Проверка:** review — шаблон эксперимента требует колонку baseline

### EVAL-004 · MUST · Стохастические конфигурации прогоняются минимум 3 раза, результаты публикуются с доверительными интервалами
- **Почему:** одно среднее значение без разброса не принимают ни ревьюеры, ни кураторы. Интервалы считаются bootstrap'ом.
- **Проверка:** review + auto:test — раннер считает CI по умолчанию [todo]

### EVAL-005 · MUST · Контаминация учитывается и отчитывается отдельно
- **Почему:** известные маршруты могли попасть в обучающие данные модели. Нужен контрольный срез (например, временной или с переформулированными запросами).
- **Проверка:** review

### EVAL-006 · MUST · Неудачные эксперименты фиксируются наравне с удачными
- **Почему:** «не вышло» с причиной тоже является результатом и материалом для статьи и ВКР.
- **Проверка:** review — запись в `eval/runs/` и журнале экспериментов

### EVAL-007 · SHOULD · Гипотезы, метрики и аблации записываются в `docs/paper/protocol.md` до запуска
- **Почему:** предрегистрация защищает от подгонки выводов под результат.
- **Проверка:** review — сабагент `reviewer-2`
