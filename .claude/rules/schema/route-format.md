# SCHEMA — Формат маршрута (RouteSpec)

> Формат является публичным контрактом и самостоятельным продуктом проекта. См. ADR-0003.

### SCHEMA-001 · MUST · JSON Schema (draft 2020-12) в `schemas/route/` — единственный источник истины
- **Почему:** типы Python и TS генерируются из схемы. Ручные дубликаты расходятся.
- **Проверка:** auto:ci — после codegen дифф должен быть пустым [todo]

### SCHEMA-002 · MUST · Формат версионируется по SemVer через поле `schema_version`
- **Почему:** breaking-изменение требует major-версии, миграции старых документов и записи в CHANGELOG формата.
- **Проверка:** auto:ci — тест миграции на всех примерах прошлых версий [todo]

### SCHEMA-003 · MUST · У каждой версии есть валидные и невалидные примеры
- **Почему:** примеры одновременно служат документацией, тестами и демо для README.
- **Проверка:** auto:ci — валидные примеры проходят, невалидные падают с ожидаемой ошибкой [todo]

### SCHEMA-004 · MUST · Вещество идентифицируется каноническим SMILES и InChIKey, вычисленными RDKit
- **Почему:** названия неоднозначны, а LLM путает структуры. Имя является атрибутом, а не ключом.
- **Проверка:** auto:test [todo]

### SCHEMA-005 · MUST · Единицы измерения указываются явно
- **Почему:** «80» без единицы может означать °C, процент или минуты. Используется объект `{value, unit}` с перечнем допустимых единиц.
- **Проверка:** auto:schema [todo]

### SCHEMA-006 · SHOULD · Конвертеры внешних форматов являются отдельными модулями с round-trip тестами
- **Почему:** конвертеры из AiZynthFinder, ASKCOS, Syntheseus и ORD открывают проекту вход в экосистему.
- **Проверка:** auto:test [todo]
