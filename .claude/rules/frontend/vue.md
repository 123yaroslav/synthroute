# UI — Фронтенд и визуализация

> Vue 3 + TypeScript + Vue Flow. Пользователь — фармаколог или технолог: что он должен понять за 10 секунд?

### UI-001 · MUST · Vue 3 Composition API (`<script setup>`) и строгий TypeScript
- **Почему:** единый стиль кода и типы, сгенерированные из RouteSpec (SCHEMA-001).
- **Проверка:** auto:ci — `vue-tsc --noEmit` и eslint [todo]

### UI-002 · MUST · Статус доверия виден без клика и кодируется не только цветом
- **Почему:** цвет, иконка и текст вместе работают при дальтонизме и при печати в PDF. Кодировка одна на весь интерфейс.
- **Проверка:** review + auto:test — компонентный тест бейджа статуса [todo]

### UI-003 · MUST · Один экран — одна мысль: важное крупно, детали по клику
- **Почему:** схема маршрута показывает главное, а карточка стадии раскрывает источники, проверки и масштаб.
- **Проверка:** review

### UI-004 · MUST · Пустые состояния и ошибки подсказывают следующее действие
- **Почему:** сообщение «Ничего не найдено» должно продолжаться фразой «попробуйте…».
- **Проверка:** review

### UI-005 · MUST · Экспортированный HTML полностью автономен
- **Почему:** файл открывается без интернета. Структуры вставлены заранее отрендеренными SVG, данные встроены.
- **Проверка:** auto:test — Playwright открывает экспорт с отключённой сетью [todo]

### UI-006 · SHOULD · Дизайн-токены собраны в одном месте, терминология взята из `docs/glossary.md`
- **Почему:** единые цвета, шрифты и термины во всём интерфейсе.
- **Проверка:** review

### UI-007 · SHOULD · Базовая доступность: контраст AA и навигация по графу с клавиатуры
- **Почему:** профессиональный инструмент, которым пользуются часами.
- **Проверка:** review
