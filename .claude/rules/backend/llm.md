# LLM — Слой моделей и промпты

> Модель не главное. Главное — обвязка вокруг неё, и модель меняется одной настройкой.

### LLM-001 · MUST · Все вызовы моделей идут через `app/llm/gateway.py`
- **Почему:** единая точка для смены провайдера, лимитов, логирования стоимости и кассет.
- **Проверка:** auto:ci — SDK провайдеров нельзя импортировать вне `app/llm/` (import-linter) [todo]

### LLM-002 · MUST · Модель выбирается конфигом по роли, а не по имени в коде
- **Почему:** роли `planner`, `extractor`, `classifier`, `chat` можно переназначить без правки логики, и это даёт leaderboard моделей.
- **Проверка:** auto:test [todo]

### LLM-003 · MUST · Промпты лежат в `prompts/` как версионированные файлы
- **Почему:** изменение промпта меняет поведение системы. Значит, нужна новая версия и eval-прогон.
- **Проверка:** review + auto:ci — версия промпта записывается в трассу каждого вызова [todo]

### LLM-004 · MUST · Вывод модели структурированный и валидируется схемой
- **Почему:** невалидный ответ повторно запрашивается с текстом ошибки (не больше N раз), затем следует явный отказ, а не «примерный» разбор.
- **Проверка:** auto:test [todo]

### LLM-005 · MUST · Каждый вызов попадает в трассу
- **Почему:** в трассе фиксируются модель, версия промпта, токены, стоимость, латентность и hash входа. Это сырьё для метрики «точность × стоимость».
- **Проверка:** auto:test [todo]

### LLM-006 · MUST · Тесты и CI работают на записанных ответах (кассеты) без сети и ключей
- **Почему:** так достигаются детерминизм, экономия лимитов и воспроизводимость результатов статьи.
- **Проверка:** auto:ci [todo]

### LLM-007 · MUST · Тексты источников в промпте считаются данными, а не инструкциями
- **Почему:** статьи и патенты могут содержать текст, похожий на инструкции (prompt injection). Источники передаются в явных ограничителях, инструкции из них не исполняются.
- **Проверка:** review + auto:test — набор инъекционных фикстур [todo]

### LLM-008 · SHOULD · Лимиты учитываются явно: rate limiter, бюджет на прогон, логируемая деградация
- **Почему:** у бесплатных ключей заметные лимиты. Переход на более дешёвую модель должен быть виден в трассе.
- **Проверка:** review
