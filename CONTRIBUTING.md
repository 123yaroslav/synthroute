# Как вносить изменения

1. Прочитайте [`AGENTS.md`](AGENTS.md): инварианты, карта и индекс правил. Агенты читают его автоматически.
2. Установите хуки: `uv tool install pre-commit && pre-commit install`.
3. Создайте ветку от `main`: `feat/…`, `fix/…`, `exp/…`, `docs/…`, `rules/…`, `chore/…` (GIT-002).
4. Коммиты пишутся по Conventional Commits на английском, например `feat(validation): add atom balance check` (GIT-003).
5. Откройте PR по шаблону: укажите затронутые ID правил, чем проверено и eval-дельту, если менялся конвейер.
6. Изменение правил начинается с issue `rule-change` или навыка `/new-rule`, затем выполняется `make rules` (ADR-0001).

Языки: документация на русском, а код, комментарии и коммиты на английском (DOC-002).
