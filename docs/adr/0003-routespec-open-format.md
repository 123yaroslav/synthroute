# ADR-0003: Собственный открытый формат маршрута RouteSpec

- **Статус:** Предложено
- **Дата:** 2026-10-13
- **Связанные правила:** SCHEMA-001…006, TRUST-001, TRUST-002

## Контекст
ТЗ требует собственный JSON-формат маршрута: вещества, стадии, масштаб, источники, статусы, метрики.
У существующих инструментов (AiZynthFinder, ASKCOS, Syntheseus, ORD) свои несовместимые представления.
Ни одно из них не описывает происхождение факта, статус проверки и параметры масштаба вместе.

## Решение
- RouteSpec задаётся в JSON Schema draft 2020-12 в `schemas/route/vX.Y/`, версионируется по SemVer, у каждой версии есть примеры.
- Типы Python и TS генерируются из схемы.
- Конвертеры из внешних форматов вынесены в отдельные модули.
- Формат публикуется как отдельная спецификация. Это вход в экосистему: «любой ретросинтез → одна схема с проверками».

## Последствия
- Плюсы: чёткий контракт между бэкендом, визуализатором и экспортом; самостоятельный продукт с потенциалом для open source.
- Минусы: нужна поддержка миграций и совместимости.
- Дальше: v0.1 с минимумом сущностей из ТЗ, затем итерации по отзывам эксперта.

## Рассмотренные альтернативы
| Вариант | Почему нет |
|---|---|
| Взять формат ORD как есть | ORD описывает отдельные реакции, а не маршрут, масштаб и статусы проверки |
| Формат AiZynthFinder | дерево ретросинтеза без условий, источников и масштаба |
| Свободный JSON без схемы | нет валидации, кодогенерации и версий |
