# Протокол исследования (предрегистрация, EVAL-007)

- **Статус:** черновик
- **Целевая площадка:** NeurIPS Datasets & Benchmarks (основная), воркшоп (промежуточная), J. Cheminformatics (параллельно)

> Фиксируем гипотезы, метрики и аблации **до** запуска экспериментов. Изменения после первого прогона на test
> вносятся только с датой и причиной в журнал ниже.

## Вопросы и гипотезы
| RQ | Гипотеза | Основная метрика |
|---|---|---|
| RQ1 | Существенная доля шагов LLM-маршрутов не проходит детерминированные проверки | step validity rate |
| RQ2 | Цикл «проверка → ремонт» повышает валидность сильнее пост-фильтра при умеренном росте стоимости | Δ validity, cost per valid route |
| RQ3 | Заметная доля ссылок LLM не подтверждается; проверка цитат это устраняет | citation grounding rate |
| RQ4 | Система находит больше различных стратегий и полнее воспроизводит известные маршруты | strategy diversity, route recall |

## Определения метрик
- **Step validity rate:** доля стадий, прошедших все обязательные проверки (список проверок и их версии фиксируются).
- **Citation grounding rate:** доля ссылок, где источник существует и цитата найдена в его тексте.
- **Route recall@k:** доля эталонных маршрутов, воспроизведённых среди k вариантов (критерий совпадения фиксируется до запуска).
- **Strategy diversity:** число кластеров по ключевым разрывам связей среди k вариантов.
- **Expert meaningfulness:** доля маршрутов, признанных экспертом технически осмысленными (слепая оценка).
- **Cost per valid route:** $ и токены на один маршрут, прошедший проверки.

## Конфигурации
| ID | Описание |
|---|---|
| B0 | LLM без обвязки (несколько моделей, одинаковый бюджет) |
| B1 | шаблонный ретросинтез без LLM |
| B2 | LLM + RAG по литературе |
| S0 | полная система (генерация, проверка, ремонт) |
| A1…An | S0 без i-й проверки, без цикла ремонта, только пост-фильтр |

## Статистика
≥ 3 прогона на конфигурацию, 95% bootstrap CI, парные сравнения на одних и тех же препаратах, поправка на множественные сравнения.

## Контаминация
Контрольный срез (например, временной или с переформулированными запросами). Результаты по нему отчитываются отдельно.

## Угрозы валидности
Один эксперт (нет межоценочной согласованности), смещение выбора препаратов, неполнота открытых источников, дрейф версий моделей.
