# Глоссарий

> Единая терминология для UI, документации и кода (UI-006). В коде используется колонка «Идентификатор».

| Термин | Идентификатор | Определение |
|---|---|---|
| МНН | `inn` | международное непатентованное название препарата (генерическое, не торговое) |
| Маршрут синтеза | `route` | последовательность стадий от доступного сырья до целевой субстанции |
| Стадия | `step` | одна химическая реакция с условиями, выходом и параметрами масштаба |
| Ретросинтез | — | анализ от целевой молекулы назад к доступным исходным веществам |
| Целевая субстанция (АФИ) | `target` | активная фармацевтическая субстанция, конечный продукт маршрута |
| SMILES | `smiles` | строковая запись структуры молекулы; в RouteSpec хранится канонический вариант RDKit |
| InChIKey | `inchikey` | хэш-идентификатор структуры; ключ вещества в RouteSpec |
| Картирование атомов | `atom_mapping` | соответствие атомов реагентов атомам продуктов |
| PMI | `pmi` | Process Mass Intensity: масса всех материалов на массу продукта |
| E-factor | `e_factor` | масса отходов на массу продукта |
| Статус проверки | `verification.status` | `literature` / `computed` / `hypothesis` / `failed` (TRUST-002) |
| Происхождение | `provenance` | источник факта: DOI, патент или запись ORD, плюс цитата |
| ICH Q3A / Q3C / Q3D / M7 | — | руководства ICH по примесям в субстанции, остаточным растворителям, элементным и мутагенным примесям |
| ORD | — | Open Reaction Database, открытая база реакций |
| Масштаб | `scale` | `lab` / `pilot` / `plant` |
